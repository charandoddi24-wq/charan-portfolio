# Rama Sri Charan Doddi — Portfolio

Dynamic, data-driven portfolio. Content lives in `data.js` and is rendered into the page by `script.js`.

## Run locally
Open `index.html` in a browser, or serve the folder:

```bash
npx --yes serve .
```

## What is dynamic
- Nav, hero, skills, projects, education, and contact are built from `PORTFOLIO` in `data.js`
- Project filters and search update the selected-work list in place
- Project details open in a dialog
- Theme preference is stored in `localStorage`
- The contact form validates input and opens a `mailto:` draft
- Active section highlighting and a scroll-progress bar follow page position

## Deploy
This folder can be deployed directly to GitHub Pages, Netlify, Vercel, or another static hosting provider.
